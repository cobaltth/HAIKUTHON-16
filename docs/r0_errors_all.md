# r0 오답 전수 분석: SigLIP이 1등을 틀린 508개, 무엇에서 틀렸나

- 모델: `google/siglip-base-patch16-224` 사전학습 그대로 (r0_zeroshot, valA score 0.5166)
- 조건: valA 질문 800개, 후보 이미지 1,600장 (valA + valB), 그룹 단위 분할
- 대상: 1등을 틀린 **508개 전부** (800개 중 63.5%)
- 방법: 정답 캡션과 "모델이 1등으로 고른 오답 이미지의 캡션"을 규칙 기반으로 비교해 무엇이 다른지 자동 라벨링 (`eval/error_analysis.py`). 라벨별로 캡션을 직접 읽어 검수하고, 대표 쌍은 이미지까지 확인했다.
- 결과 데이터: `docs/r0_errors_all.json` (사례별 라벨·차이)

## 1. 요약

### 1.1 핵심 결론
1. **508개 중 507개(99.8%)는 모델이 정답의 "형제"를 1등으로 골랐다.** 형제 = 등장하는 물체 종류가 똑같고 색·개수·관계 같은 세부만 다른 이미지. 모델이 엉뚱한 장면을 고른 경우는 1개뿐이다.
   - 앞선 분석의 72%는 하한값이었다. 그룹 규칙이 단수/복수(`donut`/`donuts`, `cactus`/`cacti`)와 수식어(`round tray`, `stone cube`)를 다르게 취급해 형제를 놓쳤기 때문이다. 정규화 후 366개 → 507개.
2. **절반 이상(273개, 53.7%)은 두 캡션의 단어 구성이 사실상 같다.** 색·관계어·개수·재질 어휘가 전부 같고, "어떤 속성이 어떤 물체에 붙는지" 또는 "관계의 방향"만 다르다. 임베딩 모델의 구조적 약점(bag-of-words처럼 동작)에 정면으로 걸리는 유형이다.
3. **정답은 거의 항상 바로 뒤에 있다.** 정답 순위가 2위 37.4%, 2~5위 89.6%, 6~9위 10.4%, 10위 밖 0%. 상위 5개만 정밀하게 다시 보면 오답의 90%를 바로잡을 기회가 있다.
4. 대표 쌍 6개를 이미지로 확인한 결과 **전부 이미지가 캡션대로 정확히 그려져 있었다.** 즉 이 오답들은 라벨 잡음이 아니라 모델이 실제로 구분하지 못한 것이다.

## 2. 유형별 해설

### 2.1 같은 단어, 결합·관계 방향만 다름 (273개, 53.7%)
**무엇이 다른가:** 두 캡션에 나오는 색·재질·관계어가 같고, 그것이 어느 물체에 붙는지 또는 관계의 방향만 다르다.
- 색 결합 교환: 1218 "**노랑** 스케이트보드 + **빨강** 사과" ↔ 1539 "**빨강** 스케이트보드 + **노랑** 사과"
- 물체-받침 교환: 0092 "스테이플러가 **회색 벤치** 위, 노랑 의자 옆" ↔ 0902 "스테이플러가 **회색 의자** 위, 노랑 벤치 옆"
- 관계 방향 반전: 3519 "붓이 닭들 **위**" ↔ 2699 "닭들이 붓 **위**", 0048 "셔츠가 칼 위" ↔ 3792 "칼이 셔츠 위"
- 재질 결합 교환: 1903 "**검은 돌** 큐브 2개 + 빨간 침낭" ↔ 3461 "**빨간 돌** 큐브 2개 + 검은 침낭"

**왜 SigLIP이 어려운가:** 문장 전체를 벡터 하나로 요약해 코사인 유사도로 비교하는 구조라, 같은 단어 묶음이면 벡터가 거의 같아진다. 이미지 쪽도 "회색 가구 하나, 노랑 가구 하나"처럼 구성 요소가 같아 차이가 작다.

**대응:** 임베딩 학습만으로는 한계가 크다 (헤드만 학습한 ablation에서 형제 배치·색 결합 hard negative가 효과 없음). **VLM 재정렬이 가장 효과적일 유형.** 정답이 2~5위에 91% 있으므로 K=5 재정렬로 대부분 포괄된다.

### 2.2 관계어가 다름 (75개, 14.8%)
**무엇이 다른가:** 관계의 종류 자체가 다르다. 가장 많은 조합: `next to ↔ on` 21건, `next to ↔ inside` 13건, `below ↔ above` 14건, `left ↔ right` 4건.
- 2811 "연필이 검은 그릇 **옆**" ↔ 2545 "검은 그릇 **안에** 연필" (이미지로 보면 차이가 매우 뚜렷한데도 틀림)
- 1236 "콘이 빨간 벤치 **옆**" ↔ 1003 "콘이 빨간 벤치 **위에 놓임**"

**왜 어려운가:** 물체와 색이 같으면 관계어 한두 단어 차이는 텍스트 벡터에 작게 반영된다. 이미지에서도 물체 위치만 다르고 구성 요소는 같다.

**대응:** 관계 뒤집기 hard negative(`rel`), 좌우 반전+left↔right 교환 증강, VLM 재정렬.

### 2.3 개수 (66개, 13.0%)
**무엇이 다른가:** 대부분 **개수가 다른 물체로 옮겨간** 경우다 (전체 개수는 비슷).
- 0015 "로봇 1개, 도넛 2개" ↔ 2162 "로봇 2개, 도넛 1개"
- 3970 "비행기 2대, 헬리콥터 1대" ↔ 0667 "비행기 1대, 헬리콥터 2대"
- 3602 "선인장 1개, 덤벨 2개" ↔ 0099 "선인장 2개, 덤벨 1개"

**왜 어려운가:** 임베딩 모델은 개수 세기에 약하고, "two"라는 단어가 양쪽 캡션에 다 있어 어느 물체에 붙었는지가 사라진다. 결합 교환의 개수 버전이다.

**대응:** **개수 교환 hard negative가 현재 증강 도구에 없다** (one↔two 교환 추가 필요). VLM 재정렬 (개수 확인).

### 2.4 색 (58개, 11.4%)
**무엇이 다른가:** 한 물체의 색만 다르다 (결합 교환이 아니라 실제로 다른 색).
- 0009 드라이버 **파랑** ↔ 0040 **검정**, 0033 새 **갈색** ↔ 1056 **노랑**, 1055 공 **베이지** ↔ 2974 **검정**

**왜 어려운가:** 바뀐 물체가 화면에서 작은 경우가 많다. 224px로 줄여 벡터 하나로 요약하면 작은 물체의 색 정보는 비중이 작다. 다른 유형보다 정답이 6위 이하로 밀린 비율이 높다(19%).

**대응:** 고해상도 백본(SigLIP 384/512), 색 hard negative, VLM 재정렬.

### 2.5 자세·열림 상태 (41개, 8.1%)
- 3687 사람이 **웅크림** ↔ 3050 **서 있음**, 2967 **웅크림** ↔ 1112 **무릎 꿇음**, 0035 **누움** ↔ 3248 **서 있음**
- 열림/닫힘(가방, 상자)도 포함

**대응:** 자세 바꾸기 hard negative(현재 없음, 추가 후보), VLM 재정렬. 정답이 2~5위에 95% 있어서 재정렬 효과가 클 유형.

### 2.6 재질 (11개)·무늬 (10개)
- 재질: 0025 금속 ↔ 나무, 1450 **고리버들** 물뿌리개 ↔ **금속** (+개수 교환)
- 무늬: 2625 단색 운동화 ↔ 1341 **줄무늬** 운동화, 2202 줄무늬 핸드백 ↔ 3027 단색
- 빈도는 낮지만 작은 물체의 표면 질감이라 임베딩이 잡기 어렵다.

### 2.7 형제가 아닌 오답 (1개)
- 0327 "갈색 개 + 별 모양 블록(수채화)" ↔ 0190 "꽃병 + 별 모양 블록(구아슈)". 물체·화풍·조명이 다 다른데도 1등이 된 유일한 사례. "흰 별 모양 블록"이 두 장면의 공통 핵심 물체라서 그쪽에 끌려간 것으로 보인다.

## 3. 검수 결과와 분류기 한계

### 3.1 수동 검수
- 라벨별 2~3쌍씩 약 20쌍의 캡션을 직접 읽어 라벨을 확인했다. 이 과정에서 오탐 패턴을 찾아 분류기를 고쳤다 (아래 3.2).
- 기준 사례 6쌍(0009/0040 색, 0033/1056 색, 0092/0902 결합, 0048/3792 결합·관계, 0015/2162 개수, 0062/0605 좌우 관계)의 라벨이 수정 후에도 유지되는 것을 확인했다.
- **이미지 직접 확인 (6쌍):** 1218/1539(색 결합), 3970/0667(개수), 2811/2545(옆↔안), 3687/3050(웅크림↔서 있음), 2625/1341(단색↔줄무늬), 3519/2699(위아래 반전). 6쌍 모두 이미지가 캡션대로 정확히 달랐다. 라벨 잡음이 아니라 모델의 실패다.
  - 예외적으로 앞서 본 0062/0605(좌우 관계)는 정면 시점이라 이미지에서도 좌우가 애매했다. 관계 유형 일부에는 이런 애매한 생성 이미지가 섞여 있을 수 있다.

### 3.2 검수 중 고친 오탐
| 오탐 | 예 | 수정 |
|---|---|---|
| 모양·재질 수식어를 물체로 착각해 "개수 차이"로 분류 | `one round tray`, `two stone cubes` | 수식어 사전(round, square, stone, leather 등) 추가 |
| 단수/복수·불규칙 복수 | `cactus`/`cacti`, `donut`/`donuts` | 불규칙 복수 사전, 단수화 규칙 보완 |
| 동사 형태 차이를 다른 자세로 분류 | `standing` vs `stand`, `wearing` vs `wears` | 동사형 통일 |
| 조명 표현을 시점으로 분류 | "lit from the side" → 측면 시점 | 시점 패턴에서 제외, 조명으로 분류 |
| "The scene contains one ..."을 '안에 있음' 관계로 분류 | | `containing one`만 관계로 인정 |
| 색 단어 `orange`(과일)를 물체로 인식 | | 물체 사전에서 색 단어 제외 |
| `solid white` vs `solid-colored` | | 무늬 표기 통일 |

### 3.3 남은 한계
- **관계어 라벨에는 같은 관계를 다르게 쓴 표현이 일부 섞일 수 있다.** 예: "그릇이 연필을 담고 있음(holds/containing)" ↔ "연필이 그릇 안에 있음(inside)". 검수한 관계 사례 대부분은 실제로 관계가 달랐지만, 14.8%라는 비율에는 소량의 오차가 있다.
- "같은 단어, 결합·관계 방향만 다름"은 결합 교환과 관계 방향 반전을 **구분하지 않는다.** 둘을 나누려면 문장을 (물체, 속성, 관계) 구조로 파싱해야 한다.
- 물체 명사는 "개수어 바로 뒤에 2회 이상 나온 단어" 사전으로 판단한다. `tennis ball`/`tennis racket`처럼 첫 단어가 같은 복합명사는 같은 물체로 볼 수 있다.
- 분류는 캡션 비교 기반이다. 이미지가 캡션과 다르게 생성된 경우(라벨 잡음)는 자동으로 잡지 못한다. 이미지 확인은 대표 6쌍에 한정했다.

## 시사점 (우리 전략에 연결)
1. **VLM 재정렬이 맞는 방향이다.** 오답의 99.8%가 형제 간 세부 구분 실패이고, 정답이 2~5위에 89.6% 있다. K=5 재정렬이면 오답의 약 90%를 고칠 기회가 생긴다 (단, 테스트는 후보가 10배라 정답 순위가 더 밀린다).
2. **임베딩 학습은 "결합 교환"보다 "색·자세·개수"처럼 어휘가 달라지는 유형에서 이득을 노리는 게 현실적이다.** 결합 교환(53.7%)은 VLM에 맡긴다.
3. **증강 도구 보완 후보:** 개수 교환(one↔two를 다른 물체로 이동), 자세 바꾸기(standing↔crouching 등), 관계 교환(next to↔on/inside).
4. 그룹 분할의 형제 정의도 단수/복수 정규화로 고치면, 검증 세트가 테스트 조건을 더 정확히 흉내 낸다.
